# BASIS RSI forward protocol v1

The authorized experiment lasts thirty calendar days from its recorded mandate start, subject to actual Guest Pass access. The local experiment journal is the continuous record; its first account observation is the permanent performance baseline. Existing tapes, stars, wallets, and exploratory reports remain evidence from their own periods.

Research and execution sessions use the BASIS and thinkorswim graphical interfaces. Every trading session verifies the visible paperMoney identity. Reuse the signed-in browser tab. Quotes inherit the venue's actual delay label; retrieval time is never represented as exchange time. BASIS CLI work supports engineering, historical experiments and the evidence journal. No order submission API is added.

Initial risk policy: defined-risk option positions, maximum loss per position at most 0.5% of initial account equity, aggregate maximum loss at most 2%, initially one structure per independent hypothesis. Correlated propositions on one underlying share the aggregate limit. These are experimental limits, not optimized position sizing. Revisions require a recorded reason and a future activation time.

Before entry, freeze a BASIS-derived PLAN with captured signal/source IDs and clocks, model and strategy versions, exact contract legs and expiry, executable venue quotes, quote delay, estimated costs, maximum loss, the testable hypothesis, entry criteria and exit conditions. A positive displayed EV alone is insufficient: examine monitoring/resolution semantics, model sensitivity, actual quote calibration, latency and the empirical evidence. Reject an economics-invalid quote or an incompatible product mapping. Deribit contracts do not authorize an assumed ETF/futures substitute.

Forward paperMoney fills are FILL events carrying actual broker fill IDs, structure quantities, exact contracts, gross cash per structure and actual fees. An unfilled order is ORDER evidence, not performance. MARK evidence records an executable quote-based liquidation estimate and its quote status, separate from actual fills. Unknown fees are null; later confirmed costs append COST evidence linked to the original fill, preserving the original observation. FIFO realizes partial closes. Account observations supply equity and buying power; drawdown is explicitly sampled, not continuous.

For each meaningful revision record the Git revision, motivating evidence, historical tests, forward activation time, and subsequent results. Exploratory samples are not forward performance. Keep rejected hypotheses, missed opportunities, adverse outcomes and prior versions. Report performance by signal class and model/strategy version, compare with no trade, and add simple alternative benchmarks only with clearly stated quotes and timing. Never reset the baseline or revise earlier source Q values to improve a result.

Iteration 1 adds evidence accounting and diagnostics. `quote-audit-1.0` inverts OTM bid/mid/ask prices under zero-carry European GBM, then compares the current continuous touch Q with XNYS regular-session monitoring. Prices still evolve through nights/weekends; those intervals cannot resolve a regular-session touch. Brownian bridges integrate within sessions. Monte Carlo error describes numerical sampling only. American pricing, carry, tenor, variance allocation, Pyth reference prices and physical versus risk-neutral differences remain limitations. This diagnostic is not an activated replacement probability model or a trading edge.

The persistent agent goal retains the mandate across continuations. It does not guarantee the computer, browser login, or dispatcher will remain available for thirty days. At each resumed session read the local journal and this protocol first, record unavailable access, and proceed with independent research/engineering when execution access is missing. Do not fabricate unattended sessions or fills.

At the end produce every trade/fill/cost/outcome, supported scientific findings and remaining uncertainty, the engineering record and tests, the best supported functioning revision, and an evaluation separating demonstrated progress from hypotheses.
