GAP = (PM YES − OPT YES) × 100 pp. Positive = conventional exposure relatively CHEAP; negative = relatively RICH. REL = abs(PM − OPT) / OPT. REL is undefined when OPT is zero. This is not position sizing.

SPREAD/MID approximates a digital using finite call spreads. IV/TOUCH uses a flat-volatility model. PROXY means assumptions remain: select the row to inspect model confidence, exact wording, source differences, inputs and raw record IDs. Tail REL can be enormous because the denominator is tiny.

Trend measures absolute-gap widening/closing. PM TRAVEL and OPT TRAVEL describe movement, not causal leadership. Lag correlations and spot residuals remain exploratory associations.
